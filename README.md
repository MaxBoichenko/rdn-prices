# Цены РДН: Польша, Румыния, Словакия, Венгрия, Украина

Сайт показывает цены рынка на сутки вперёд (РДН / day-ahead) в **EUR/MWh** и обновляется **сам, каждый день**.
Всё работает бесплатно на GitHub: GitHub Actions собирает данные по расписанию, GitHub Pages показывает сайт.

**Что есть на сайте**
- Вкладка «День»: карточки Base / Peak / Off-peak / мин / макс и изменение к предыдущему дню; почасовой график; таблица-теплокарта; спред любой пары стран по часам; матрица спредов Base.
- Вкладка «Период»: Base / Peak / Off-peak по дням за 30–365 дней, средние по месяцам.
- Вкладка «Аналитика» (12 месяцев, конечный месяц выбирается):
  - сводные показатели за 12 месяцев по каждой стране: Base, Peak, Off-peak, Peak/Base, самый дешёвый и самый дорогой час, число часов с отрицательной ценой, волатильность σ, изменение Base к предыдущим 12 месяцам;
  - помесячная динамика индексов РДН (Base / Peak / Off-peak) с изменением м/м;
  - межрыночные спреды Base «Украина − PL / SK / HU / RO» по месяцам и доля часов, когда Украина дороже;
  - межгосударственные перетоки Украины по границам PL, SK, HU, RO, MD: импорт, экспорт, сальдо (ГВт·ч);
  - сальдо экспорта/импорта PL, SK, HU, RO, UA по всем границам каждой страны.
  Ссылка сразу на аналитику: `…/?view=analytics`.
- Переключатели: время CET или Киев/Кишинёв, язык RU/EN, выбор стран, выгрузка в CSV (то, что на экране).
- Кнопка **«Excel: все данные»** — один файл .xlsx со всей накопленной историей: листы «Инфо», «Часовые цены», «Дневные индексы», «Месячные индексы», «Спреды UA», «Перетоки по суткам», «Перетоки и сальдо». Даты и часы — в часовом поясе, выбранном на сайте.
- Ссылка на конкретный день: `…/?date=2026-11-24`.

**Откуда данные**

| Страна | Источник |
|---|---|
| PL, RO, SK, HU | ENTSO-E Transparency Platform (документ A44 «Day-ahead prices») |
| UA | ENTSO-E (зона ОЭС Украины). Если там нет полных суток, данные берутся у ОРЕЕ (oree.com.ua) в грн и пересчитываются в EUR по курсу НБУ на дату поставки |

| Перетоки | ENTSO-E, фактические физические перетоки (A11) по всем границам PL, SK, HU, RO, UA (включая DE, CZ, LT, SE4, AT, HR, RS, SI, BG, MD); суммы за сутки по CET |

Рынки с 15-минутным шагом сводятся к часам: часовая цена равна среднему четырёх 15-минуток. Peak — это 08:00–20:00 в выбранном на сайте часовом поясе.

## Запуск: один раз, примерно 20 минут

### 1. Токен ENTSO-E (бесплатно)
1. Зарегистрируйтесь на https://transparency.entsoe.eu/ (кнопка Login → Register).
2. Отправьте письмо на **transparency@entsoe.eu** с темой `Restful API access`. В тексте укажите e-mail, на который зарегистрирован аккаунт. Доступ обычно открывают в течение 1–3 рабочих дней.
3. После этого в разделе **My Account Settings** нажмите **Generate a new token** и скопируйте токен.

### 2. Репозиторий на GitHub
1. Создайте аккаунт на https://github.com (или используйте существующий; лучше аккаунт компании).
2. **New repository** → название, например `rdn-prices` → **Public**. Бесплатный GitHub Pages работает только с публичными репозиториями.
3. **Add file → Upload files** → перетащите в окно **содержимое** этой папки целиком, включая скрытую папку `.github` → **Commit changes**.
   Если папку `.github` перетащить не получилось: **Add file → Create new file**, имя `.github/workflows/update.yml`, вставьте содержимое файла и сохраните.

### 3. Вставить токен
**Settings → Secrets and variables → Actions → New repository secret**
- Name: `ENTSOE_TOKEN`
- Secret: токен из шага 1

### 4. Включить сайт
**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save.**
Через 1–2 минуты сайт откроется по адресу `https://<ваш-логин>.github.io/rdn-prices/`.

### 5. Загрузить историю
**Actions → «Обновление цен РДН» → Run workflow**. В поле «Загрузить историю с даты» укажите, например, `2025-10-01` и запустите.
Цены загружаются за несколько минут. Перетоки (40 направлений) — дольше: за год примерно 10–20 минут. Для 12-месячной аналитики и сравнения с предыдущим годом загрузите историю минимум за 2 года.
Перетоки публикуются по факту, поэтому они появляются на сайте за прошедшие сутки, а не за завтра.

Дальше ничего делать не нужно: сборщик запускается сам 4 раза в день (около 12:55, 13:40, 14:30 и 17:30 CET) и забирает цены на завтра, как только они опубликованы.

## Если что-то не так
- **Нет данных за сегодня или завтра.** Откройте Actions → последний запуск → шаг «Сбор цен»: там видно, сколько часов получено по каждой стране и есть ли ошибки. GitHub иногда запускает задачи по расписанию с задержкой до 15–30 минут.
- **«ENTSO-E: неверный токен (401)».** Проверьте секрет `ENTSOE_TOKEN` и то, что ENTSO-E уже открыли вам доступ к API.
- **Нет Украины.** Если ENTSO-E не отдаёт цены Украины, сборщик берёт их у ОРЕЕ. Если ОРЕЕ поменяет страницу, в логе появится `UA/ОРЕЕ … ОШИБКА` или `часов: 0`, и функцию `fetch_oree_day` в `scripts/fetch_prices.py` нужно будет поправить.
- **Нет перетоков по какой-то границе.** В логе видно строки `[flow] UA>HU ... часов 0`. Если ENTSO-E не публикует переток по границе (например, Украина–Молдова), он просто не попадёт в таблицу, а сальдо страны будет посчитано по остальным границам.
- **Задачи по расписанию остановились.** GitHub отключает расписание в репозитории, где 60 дней не было коммитов. Сборщик коммитит данные каждый день, так что этого не произойдёт, пока он работает.

## Своё доменное имя (по желанию)
Settings → Pages → Custom domain, например `rdn.вашакомпания.com`, и CNAME-запись у регистратора домена на `<логин>.github.io`.

## Локальный запуск
```bash
pip install -r scripts/requirements.txt
ENTSOE_TOKEN=ваш_токен python scripts/fetch_prices.py --start 2026-11-01
cd docs && python -m http.server 8000     # открыть http://localhost:8000
```

## Структура
```
.github/workflows/update.yml   расписание сбора данных
scripts/fetch_prices.py        сборщик: ENTSO-E, ОРЕЕ, курс НБУ
docs/                          сайт (GitHub Pages)
  index.html, app.js, style.css
  data/YYYY-MM.json            часовые цены (UTC), EUR/MWh
  data/meta.json               время обновления, список месяцев, источники
  data/flows/YYYY-MM.json      перетоки, MWh за сутки (CET), ключ "PL>UA" = из PL в UA
tests/test_parsers.py          тесты разбора ответов ENTSO-E и ОРЕЕ
```
